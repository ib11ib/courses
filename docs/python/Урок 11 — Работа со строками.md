## Строка — почти как список

Строка — это последовательность символов. Индексы и срезы работают так же, как у списков:

```python
word = "Программирование"
print(word[0])      # П
print(word[-1])     # е
print(word[0:5])    # Прогр
print(len(word))    # 16
```

Но **изменить** букву в строке нельзя: `word[0] = "п"` — ошибка. Строки «неизменяемые». Чтобы изменить — создают **новую** строку.

## Методы строк

Каждый метод возвращает **новую** строку, исходная не меняется.

```python
text = "  Привет, Мир!  "

print(text.upper())      # "  ПРИВЕТ, МИР!  "  — всё заглавными
print(text.lower())      # "  привет, мир!  "  — всё строчными
print(text.strip())      # "Привет, Мир!"      — убрать пробелы по краям
print(text.replace("Мир", "Python"))   # "  Привет, Python!  "
```

> [!tip] Главный приём при вводе
> Пользователь может ввести `Да`, `ДА`, ` да ` — для программы это всё разное. Решение:
> ```python
> answer = input("Продолжить? ").strip().lower()
> if answer == "да":
>     ...
> ```
> Методы можно писать цепочкой: сначала убрали пробелы, потом сделали строчными.

### Поиск

```python
email = "ivan.petrov@mail.ru"

print("@" in email)              # True — есть ли символ
print(email.find("@"))           # 11 — номер позиции (или -1, если нет)
print(email.count("e"))          # 1 — сколько раз встречается
print(email.startswith("ivan"))  # True — начинается с...
print(email.endswith(".ru"))     # True — заканчивается на...
```

### Проверки содержимого

```python
print("2026".isdigit())    # True — только цифры
print("abc".isalpha())     # True — только буквы
print("Abc".isupper())     # False — все ли заглавные
```

`isdigit()` пригодится, чтобы проверить ввод **перед** `int()`.

## split и join — разбить и собрать

Это одни из самых полезных методов.

```python
line = "хлеб,молоко,сыр,яйца"
items = line.split(",")        # разбить по запятой → список
print(items)                   # ['хлеб', 'молоко', 'сыр', 'яйца']

sentence = "Я учу Python каждый день"
words = sentence.split()       # без аргумента — по пробелам
print(len(words))              # 5 — количество слов

result = " | ".join(items)     # собрать список в строку через " | "
print(result)                  # хлеб | молоко | сыр | яйца
```

> Аналогия для IT: `split` — это как «Текст по столбцам» в Excel. `join` — обратная операция, «склеить столбцы».

## Перебор строки и сборка новой

```python
phrase = "Привет мир"
result = ""
for char in phrase:
    if char != " ":
        result += char
print(result)   # Приветмир
```

## Запомнить

- Строки неизменяемы — методы возвращают **новую** строку.
- `input().strip().lower()` — стандартная обработка ответа пользователя.
- `split()` — строка → список, `"разделитель".join(список)` — список → строка.
