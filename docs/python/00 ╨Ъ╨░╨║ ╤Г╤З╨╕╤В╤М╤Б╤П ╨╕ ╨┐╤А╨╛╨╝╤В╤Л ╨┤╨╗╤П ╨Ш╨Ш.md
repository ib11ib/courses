# Как учиться и как проверяться у нейросети

← [[00 Старт здесь]]

## Распорядок на один час

| Время | Что делать |
|---|---|
| 5 мин | Повторить прошлый урок: перечитать раздел «Запомнить» |
| 20 мин | Прочитать теорию. **Каждый пример набрать руками** (не копировать!) и запустить |
| 30 мин | Решать задачи. Каждую задачу — отправить ИИ на проверку |
| 5 мин | Отметить галочки в трекере, записать вопросы в «Журнал вопросов» |

Один урок рассчитан на 1–2 дня. Не успели — ничего страшного, продолжаем завтра с того же места. **Лучше медленно, но каждый день**, чем 5 часов раз в неделю.

## Три правила

1. **Набирать код руками.** Пальцы запоминают синтаксис быстрее глаз.
2. **Ошибка — это нормально.** Красный текст в консоли — не провал, а подсказка. Профессионалы видят ошибки десятки раз в день.
3. **Сначала сам, потом ИИ.** Минимум 15 минут думать над задачей самостоятельно. Только потом — подсказка.

## Как работать с нейросетью

Подойдёт ChatGPT, Claude, GigaChat, DeepSeek — любая. Порядок такой:

1. Открыть **новый чат** в начале каждого урока.
2. Первым сообщением вставить **Главный промт наставника** (ниже). Нейросеть ответит, что готова.
3. Дальше для каждой задачи копировать **промт проверки** из урока, вставлять туда свой код и то, что вывела программа.
4. Исправлять код по замечаниям и отправлять снова, пока наставник не поставит «ЗАЧЁТ».
5. Только после «ЗАЧЁТ» ставить галочку у задачи.

> [!warning] Честный уговор
> Не просить у нейросети готовое решение в обход наставника (в другом чате, «по-хорошему»). Готовый код, который вы не написали сами, не учит ничему — это как смотреть, как другой человек ходит в спортзал.

## 🧑‍🏫 Главный промт наставника

Скопировать целиком и отправить первым сообщением в новом чате:

```
Ты — строгий, но справедливый наставник по Python. Твой ученик — взрослый новичок. Он уверенно пользуется компьютером (файлы, программы, интернет, Windows), но никогда не программировал. Он проходит курс «Питон с нуля» по урокам и присылает тебе решения задач.

Твои правила:
1. НИКОГДА не пиши за ученика готовое решение задачи целиком и не переписывай его код в исправленном виде. Даже если он просит. Твоя задача — чтобы он сам дошёл до ответа.
2. Проверяй решение по условию задачи и критериям, которые он пришлёт. Запускай код мысленно: проверь и обычные, и «неудобные» входные данные (ноль, пустая строка, отрицательное число), если это уместно для урока.
3. Ответ всегда давай в таком формате:
   ВЕРДИКТ: ЗАЧЁТ или НА ДОРАБОТКУ
   ЧТО ХОРОШО: 1–2 пункта, коротко и по делу (без лести).
   ОШИБКИ: список. Для каждой: номер строки, что не так и ПОЧЕМУ — простыми словами. Если ошибок нет — напиши «нет».
   ПОДСКАЗКА: одна подсказка-наводка к самой важной ошибке. Наводящий вопрос или название того, что нужно использовать, но не готовый код.
   ВОПРОС НА ПОНИМАНИЕ: один короткий вопрос по его же коду, чтобы убедиться, что он понимает, как код работает. «ЗАЧЁТ» окончательный, только когда он правильно ответит на этот вопрос.
4. Если код работает, но написан неряшливо (непонятные имена переменных вроде a, b, x1; лишний повторяющийся код), — это повод для замечания. Зачёт можно ставить, но замечание обязательно.
5. Не используй и не советуй темы, которых ещё не было в курсе (номер урока он указывает). Если решение можно сделать проще с помощью будущих тем — просто не упоминай их.
6. Если ученик пишет «я застрял», давай подсказки лесенкой: сначала самая общая, потом конкретнее. Максимум — показать ОДНУ строку кода или фрагмент строки, но не всё решение.
7. Объясняй термины русскими словами и бытовыми аналогиями. Ученик понимает IT, поэтому аналогии с файлами, папками, Excel, сетью — хорошо заходят.
8. Пиши кратко. Без вступлений вроде «Отличный вопрос!». Обращайся на «вы».

Если понял правила, ответь одной фразой: «Готов. Присылайте урок, номер задачи и код.»
```

## Промт проверки задачи (общий шаблон)

В каждом уроке есть готовый промт с условием. Если нужно проверить что-то своё — шаблон:

````
Урок №__ , задача №__.
Условие: (вставить условие)

Мой код:
```python
(вставить код)
```

Что вывела программа (или текст ошибки):
```
(вставить)
```
````

## 🆘 Промт «Я застрял»

````
Урок №__, задача №__. Я застрял.
Условие: (вставить условие)
Что я уже попробовал:
```python
(вставить код, даже если он не работает)
```
Где именно я не понимаю: (написать своими словами, например «не понимаю, как сделать, чтобы вопрос повторялся»)
Дай мне ОДНУ подсказку, самую общую.
````

Если после подсказки всё равно не получается — написать: «Нужна подсказка конкретнее».

## 🐞 Промт «Объясни ошибку»

````
Урок №__. Программа выдала ошибку, я не понимаю, что она значит.
Мой код:
```python
(код)
```
Текст ошибки (полностью):
```
(ошибка)
```
Объясни простыми словами: 1) что означает эта ошибка в целом, 2) на какой строке проблема. Не исправляй код за меня — подскажи, куда смотреть.
````

## ❓ Промт «Проверь меня» (раз в 3–4 урока)

```
Я прошёл уроки с №__ по №__ курса Python: (перечислить темы из оглавления).
Устрой мне устный экзамен: задавай по ОДНОМУ вопросу, жди мой ответ, оценивай его, потом следующий вопрос. Всего 7 вопросов: 4 на понимание («что выведет этот код?»), 2 на поиск ошибки в коротком коде, 1 — написать маленький кусочек кода. В конце — оценка по 5-балльной шкале и список тем, которые стоит повторить.
```

## 📖 Промт «Объясни иначе»

```
Я прохожу урок №__ курса Python, тема: «____». Я прочитал объяснение, но не понял вот это: «____».
Объясни по-другому, через аналогию из жизни или из работы с компьютером. Дай один маленький пример кода (3–5 строк) и предложи мне угадать, что он выведет, прежде чем я его запущу.
```
