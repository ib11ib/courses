# Урок 09. Цикл for и range

← [[Урок 08 — Цикл while]] · Следующий: [[Урок 10 — Списки]]

**Цель:** освоить цикл `for` — самый частый цикл в Python.
**Время:** 1–2 дня.

## for — «для каждого»

`while` повторяет, **пока** условие правда. `for` проходит **по каждому элементу** чего-то.

```python
for letter in "Python":
    print(letter)
```
```
P
y
t
h
o
n
```

Читается: «для каждой буквы `letter` в строке `"Python"` — напечатать её». На каждом шаге в переменную `letter` по очереди кладётся очередной символ.

## range — диапазон чисел

Чаще всего `for` используют с `range` — генератором последовательности чисел.

```python
for i in range(5):
    print(i)
```
```
0
1
2
3
4
```

> [!warning] Счёт с нуля и «до, не включая»
> `range(5)` — это 0, 1, 2, 3, 4. **Пять чисел, начиная с нуля, пятёрка не входит.** В программировании счёт почти всегда начинается с нуля. Непривычно, но быстро привыкнете.

Варианты `range`:

| Запись | Числа |
|---|---|
| `range(5)` | 0, 1, 2, 3, 4 |
| `range(1, 6)` | 1, 2, 3, 4, 5 |
| `range(0, 11, 2)` | 0, 2, 4, 6, 8, 10 (шаг 2) |
| `range(10, 0, -1)` | 10, 9, 8, ..., 1 (обратный отсчёт) |

Формула: `range(начало, конец_не_включая, шаг)`.

## Сравним while и for

Числа от 1 до 5:

```python
# while
n = 1
while n <= 5:
    print(n)
    n += 1

# for — короче и без риска забыть n += 1
for n in range(1, 6):
    print(n)
```

**Когда что:**
- Знаем, сколько раз повторять (10 раз, по каждой букве) → `for`.
- Не знаем, повторяем, пока что-то не случится (пока не введут правильный пароль) → `while`.

## Повторить N раз

Если сама переменная не нужна, её принято называть `_`:

```python
for _ in range(3):
    print("Ура!")
```

## Накопление в for

```python
total = 0
for n in range(1, 101):
    total += n
print(f"Сумма чисел от 1 до 100 = {total}")   # 5050
```

## Вложенные циклы

Цикл внутри цикла. Внутренний цикл проходит **полностью** на каждом шаге внешнего.

```python
for row in range(1, 4):
    for col in range(1, 4):
        print(f"{row}x{col}={row * col}", end="  ")
    print()   # перевод строки после каждой строки таблицы
```
```
1x1=1  1x2=2  1x3=3  
2x1=2  2x2=4  2x3=6  
3x1=3  3x2=6  3x3=9  
```

`end="  "` в `print` — значит «в конце поставь два пробела вместо перехода на новую строку».

> Аналогия: часы. Минутная стрелка (внутренний цикл) проходит полный круг за каждый шаг часовой (внешний цикл).

## Запомнить

- `for x in ...:` — пройти по каждому элементу.
- `range(a, b)` — от `a` до `b`, **не включая** `b`. Счёт — с нуля.
- Знаем количество повторов → `for`; ждём события → `while`.
