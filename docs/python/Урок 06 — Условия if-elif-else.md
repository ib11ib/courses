## Сравнения

Сравнение — это вопрос, на который ответ `True` (да) или `False` (нет).

| Знак | Значит | Пример | Ответ |
|---|---|---|---|
| `==` | равно | `5 == 5` | `True` |
| `!=` | не равно | `5 != 3` | `True` |
| `>` | больше | `5 > 3` | `True` |
| `<` | меньше | `5 < 3` | `False` |
| `>=` | больше или равно | `5 >= 5` | `True` |
| `<=` | меньше или равно | `3 <= 2` | `False` |

> [!warning] `=` и `==`
> `=` — положить в коробку. `==` — **спросить**, равно ли. Перепутать их — самая частая ошибка.

Текст тоже можно сравнивать: `"да" == "да"` → `True`, но `"Да" == "да"` → `False` (регистр важен).

## if — «если»

```python
age = int(input("Ваш возраст: "))

if age >= 18:
    print("Доступ разрешён")
    print("Добро пожаловать!")

print("Программа завершена")
```

Разберём по частям:
- `if` — «если»
- `age >= 18` — условие
- **двоеточие `:`** в конце — обязательно!
- строки ниже — **с отступом в 4 пробела** (или Tab — VS Code сам превратит его в 4 пробела). Это **тело** условия: выполняется, только если условие `True`.
- `print("Программа завершена")` — без отступа, значит, это уже **не** внутри `if`, выполнится всегда.

> [!info] Отступ — это «вложенность»
> Как папки в проводнике: строки с отступом «лежат внутри» `if`. VS Code после двоеточия и Enter сам ставит отступ. Чтобы выйти из `if` — нажмите Backspace в начале строки.

## else — «иначе»

```python
temperature = float(input("Температура на улице: "))

if temperature > 0:
    print("Можно без шапки")
else:
    print("Наденьте шапку!")
```

Выполнится **ровно одна** из двух веток.

## elif — «иначе, если»

Когда вариантов больше двух:

```python
score = int(input("Баллы за экзамен (0–100): "))

if score >= 90:
    print("Отлично")
elif score >= 70:
    print("Хорошо")
elif score >= 50:
    print("Удовлетворительно")
else:
    print("Неудовлетворительно")
```

Python проверяет условия **сверху вниз** и выполняет **первое подходящее**, остальные пропускает. Поэтому для 95 баллов будет только «Отлично», хотя 95 >= 70 тоже правда.

> Аналогия: правила сортировки почты в Outlook. Письмо попадает в первую подходящую папку.

## Пример: чётное или нечётное

```python
number = int(input("Введите число: "))

if number % 2 == 0:
    print(f"{number} — чётное")
else:
    print(f"{number} — нечётное")
```

## Условие внутри условия

```python
has_ticket = input("Есть билет? (да/нет): ")

if has_ticket == "да":
    age = int(input("Возраст: "))
    if age < 12:
        print("Проходите, для детей место у окна")
    else:
        print("Проходите")
else:
    print("Сначала купите билет")
```

Двойной отступ = условие внутри условия.

## Запомнить

- `==` — сравнить, `=` — присвоить.
- После `if`, `elif`, `else` — двоеточие, тело — с отступом 4 пробела.
