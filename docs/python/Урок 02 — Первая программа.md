## Что такое программа

Программа — это **список команд**, которые компьютер выполняет **строго сверху вниз**, по одной. Как инструкция по сборке шкафа: шаг 1, шаг 2, шаг 3. Компьютер не умный — он делает ровно то, что написано, буквально.

## Команда print

`print` — «напечатать». Выводит на экран то, что в скобках.

```python
print("Добрый день!")
print("Сегодня я учу Python.")
print(2026)
```

Результат:
```
Добрый день!
Сегодня я учу Python.
2026
```

Обратите внимание:
- **Текст** пишется в кавычках: `"текст"` или `'текст'` — разницы нет.
- **Числа** — без кавычек.
- Каждый `print` начинает новую строку.

### Несколько значений через запятую

```python
print("Мне", 55, "лет")
```
```
Мне 55 лет
```
Python сам ставит пробелы между значениями.

### Пустая строка

```python
print("Первая строка")
print()
print("Третья строка")
```
`print()` без ничего — просто пустая строка, отступ.

### Python умеет считать

```python
print(2 + 3)
print(10 * 7)
print("2 + 3")
```
```
5
70
2 + 3
```
Видите разницу? `2 + 3` без кавычек — это **вычисление**. `"2 + 3"` в кавычках — это **просто текст**, Python его не трогает.

## Комментарии

Всё, что после знака `#`, Python **игнорирует**. Это заметки для человека.

```python
# Это моя первая программа
print("Привет")  # эта строка выводит приветствие
# print("Эта строка не выполнится")
```

Комментарии нужны, чтобы через месяц вы сами поняли, что тут написано. Привыкайте их писать.

## Ошибки — как их читать

Сделайте ошибку специально:

```python
print("Привет)
```

Python ответит примерно так:
```
  File "D:\Python_курс\hello.py", line 1
    print("Привет)
          ^
SyntaxError: unterminated string literal (detected at line 1)
```

Как читать — **снизу вверх**:
1. **Последняя строка** — самое главное: тип ошибки (`SyntaxError` — ошибка написания) и пояснение (`unterminated string literal` — «незакрытая строка», т.е. забыли кавычку).
2. **`line 1`** — номер строки, где проблема.
3. **Стрелочка `^`** — примерно указывает место.

Частые ошибки новичков:

| Ошибка | Что значит | Пример причины |
|---|---|---|
| `SyntaxError` | Неправильно написано | Забыли кавычку или скобку |
| `NameError: name 'pirnt' is not defined` | Python не знает такого слова | Опечатка: `pirnt` вместо `print` |
| `IndentationError` | Лишний пробел в начале строки | Строка начинается с пробела |

> [!warning] Пробел в начале строки
> В Python пробелы в начале строки **важны**. Пока что все строки должны начинаться **с самого края**, без отступа. Зачем нужны отступы — узнаем в уроке про условия.

> [!tip] Большие и маленькие буквы
> `print` и `Print` — для Python разные слова. `Print("Привет")` выдаст ошибку. Команды пишутся маленькими буквами.

## Запомнить

- `print(...)` выводит на экран. Текст — в кавычках, числа — без.
- `#` — комментарий, Python его пропускает.
- Ошибку читаем снизу вверх: тип → пояснение → номер строки.
- Регистр букв важен, лишние пробелы в начале строки — нельзя.
