# Проект 2. Домашняя бухгалтерия

← [[Проект 1 — Игра Угадай число]] · Следующий: [[Проект 3 — Викторина]]

**Время:** 6–8 дней.
**Что используем:** списки словарей, JSON, `datetime`, функции, строки, модули, форматированный вывод.

## Описание

Программа для учёта расходов и доходов. Данные хранятся в файле, можно смотреть отчёты по месяцам и категориям. Полезная вещь, которой можно реально пользоваться.

Пример работы:
```
=== ДОМАШНЯЯ БУХГАЛТЕРИЯ ===
Баланс: 34 250.00 руб.

1. Добавить расход
2. Добавить доход
3. Последние 10 операций
4. Отчёт за месяц
5. Расходы по категориям
6. Поиск
0. Выход
Выбор: 1

Сумма: 1250,50
Категории: 1-Продукты 2-Транспорт 3-Дом 4-Здоровье 5-Развлечения 6-Другое
Категория: 1
Комментарий (можно пусто): Пятёрочка
Дата (Enter — сегодня):
✅ Добавлено: 17.11.2026 | Продукты | -1 250.50 | Пятёрочка
```

Отчёт по категориям:
```
Расходы за ноябрь 2026:
Продукты      18 430.00  ████████████ 52%
Дом            9 200.00  ██████ 26%
Транспорт      4 100.00  ███ 12%
Другое         3 600.00  ██ 10%
ИТОГО         35 330.00
```

## Структура данных

Каждая операция — словарь, все операции — список, который сохраняется в `money.json`:

```python
{"date": "2026-11-17", "type": "расход", "amount": 1250.5, "category": "Продукты", "comment": "Пятёрочка"}
```

Дату храним в формате `ГГГГ-ММ-ДД` — так её легко сравнивать и сортировать, а показываем пользователю как `ДД.ММ.ГГГГ`.

> [!tip] Отдельные модули
> Попробуйте разбить проект на файлы: `storage.py` (загрузка/сохранение), `inputs.py` (надёжный ввод), `reports.py` (отчёты), `main.py` (меню). Это необязательно, но очень полезно.

## Этапы

- [ ] **Этап 0. План.** Список функций, структура данных, псевдокод меню.
- [ ] **Этап 1. Добавление и просмотр.** Меню из пунктов 1, 3, 0. Добавить расход (сумма, категория из списка, комментарий), показать все операции. Данные пока в памяти.
- [ ] **Этап 2. Сохранение.** Загрузка из `money.json` при запуске, сохранение после каждого добавления. Защита: файла нет, файл пустой.
- [ ] **Этап 3. Доходы и баланс.** Пункт 2 — добавить доход. Баланс (доходы минус расходы) показывается над меню.
- [ ] **Этап 4. Даты.** У каждой операции дата. По умолчанию — сегодня (Enter), можно ввести `ДД.ММ.ГГГГ`. Неправильная дата — повторить ввод. Пункт 3 показывает последние 10 операций по дате (подсказка: `sorted` со списком словарей — спросите наставника «как отсортировать список словарей по ключу», это новая тема `key=`).
- [ ] **Этап 5. Отчёт за месяц.** Пользователь вводит месяц и год, программа выводит все операции месяца, сумму доходов, расходов и итог.
- [ ] **Этап 6. По категориям.** Расходы за выбранный месяц, сгруппированные по категориям, с процентами и «столбиками» из символов `█` (длина пропорциональна доле).
- [ ] **Этап 7. Поиск и удаление.** Поиск операций по слову в комментарии. Удаление операции по номеру из результатов поиска (с подтверждением «Точно удалить? да/нет»).
- [ ] **Этап 8 (бонус). Экспорт в Excel.** Пункт «Экспорт»: сохранить все операции в `money.csv` через `;`, чтобы открыть в Excel. Узнайте у наставника, почему для Excel на русской Windows лучше кодировка `utf-8-sig`.
- [ ] **Этап 9. Финальное ревью.**
