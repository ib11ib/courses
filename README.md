# Мои курсы

Сайт с курсами: **https://ib11ib.github.io/courses/**

Курсы лежат в папке `docs/` как обычные заметки Obsidian (`.md`). Всё остальное сайт делает сам: меню, поиск, тёмную тему, кнопки «Скачать урок» и «Скачать весь курс (.zip)». После каждого изменения в репозитории GitHub пересобирает сайт примерно за минуту.

---

## Первый запуск (один раз, ~5 минут)

### 1. Создать репозиторий
1. Откройте https://github.com/new
2. **Repository name:** `courses`
3. Видимость **Public**: на бесплатном тарифе GitHub Pages работает только с открытыми репозиториями.
4. Галочки «Add a README» и прочие **не ставьте**.
5. Нажмите **Create repository**.

### 2. Загрузить файлы
1. Распакуйте архив `courses.zip` у себя на компьютере.
2. На странице нового репозитория нажмите ссылку **uploading an existing file**.
3. Откройте распакованную папку `courses` и перетащите в окно браузера **всё её содержимое** (не саму папку): `docs`, `hooks`, `.github`, `mkdocs.yml`, `requirements.txt`, `README.md`, `.gitignore`.
4. Дождитесь, пока все файлы загрузятся, и нажмите **Commit changes**.

> **Проверьте, что загрузилась папка `.github`.** Она нужна для сборки сайта.
> На Mac папки с точкой в начале скрыты. Чтобы их увидеть, нажмите в Finder **Cmd + Shift + .** (точка).
> Если папки всё равно нет: **Add file → Create new file**, в поле имени введите `.github/workflows/deploy.yml`, вставьте содержимое этого файла из архива и нажмите **Commit changes**.

### 3. Включить GitHub Pages
1. В репозитории откройте **Settings → Pages**.
2. В блоке **Build and deployment** в поле **Source** выберите **GitHub Actions**.

### 4. Запустить сборку
1. Откройте вкладку **Actions**.
2. Слева выберите **Сборка сайта**, справа нажмите **Run workflow → Run workflow**.
3. Через 1–2 минуты появится зелёная галочка ✅.
4. Сайт откроется по адресу **https://ib11ib.github.io/courses/**

Дальше сайт пересобирается сам после каждого изменения.

## Как добавить или изменить урок

**Добавить урок в существующий курс:**
1. Откройте папку курса, например `docs/python`.
2. Нажмите **Add file → Upload files** и перетащите `.md` файл.
3. Нажмите **Commit changes**. Через минуту урок появится на сайте.

**Поправить урок:** откройте файл на GitHub, нажмите на ✏️ (карандаш), внесите правки и нажмите **Commit changes**.

**Удалить урок:** откройте файл, нажмите **⋯ → Delete file** и затем **Commit changes**.

## Как добавить новый курс

1. Подготовьте у себя папку с заметками курса. Назовите её **латиницей**, например `unity` или `js-basics`: из этого имени получится адрес курса на сайте.
2. Откройте на GitHub папку `docs`, нажмите **Add file → Upload files** и перетащите папку целиком.
3. Нажмите **Commit changes**.

Курс сам появится на главной и во вкладках сверху. Если нужно красивое название, описание и значок, положите в папку курса файл `_course.yml` (образец в `docs/python/_course.yml`):

```yaml
title: Unity                       # коротко, для вкладки сверху
full_title: Unity для начинающих   # на карточке и в имени архива
description: Пара предложений о курсе для карточки на главной.
icon: simple/unity                 # значок, см. ниже
order: 3                           # порядок на главной
```

Значки можно подобрать на https://squidfunk.github.io/mkdocs-material/reference/icons-emojis/#search. Например, `material/language-javascript` или `simple/unity`.

## Как сайт раскладывает заметки

- **Главная страница курса** — заметка, в названии которой есть «Старт» (`00 Старт.md`). Можно указать другую в `_course.yml` строкой `start: Имя заметки`.
- **Меню курса** собирается по названиям файлов:
  - `00 …`, `01 …` → «Введение»;
  - `Урок 01 …` → «Уроки», `Неделя 01 …` → «Недели», `Проект 1 …` → «Проекты»;
  - всё остальное → «Справка».
- **Своя группа:** если в свойствах заметки (в самом начале файла, между `---`) есть поле `module: Название`, уроки группируются по этим модулям.
- **Ссылки `[[Заметка]]`** работают как в Obsidian. Картинки `![[рисунок.png]]` кладите в ту же папку курса.
- **Только для Obsidian:** таблицы Dataview и `.base` на сайте заменяются пометкой, что они работают в Obsidian. В скачанном архиве они остаются как есть.
- Сами файлы в `docs/` сайт **не меняет**: в архивах для скачивания лежат ваши оригиналы.

## Если что-то пошло не так

- **Сайт не обновился:** откройте вкладку **Actions**. Красный крестик ❌ значит, что сборка упала. Нажмите на неё и посмотрите текст ошибки. Чаще всего помогает **Re-run jobs**.
- **Репозиторий называется не `courses`:** поправьте адреса в начале файла `mkdocs.yml` (строки `site_url`, `repo_url`, `repo_name`).

## Посмотреть сайт у себя до загрузки (необязательно)

Нужен установленный Python:

```bash
pip install -r requirements.txt
mkdocs serve
```

После этого откройте http://127.0.0.1:8000 в браузере.
