## Что такое словарь

В списке элементы находим по номеру: `names[2]`. А если хочется находить по **названию**? Например, телефон по имени. Для этого — **словарь** (`dict`).

```python
phones = {
    "Анна": "+7 900 111-22-33",
    "Борис": "+7 900 444-55-66",
    "Вера": "+7 900 777-88-99",
}
print(phones["Борис"])   # +7 900 444-55-66
```

- Фигурные скобки `{}`.
- Пары `ключ: значение` через запятую.
- Обращение по ключу в квадратных скобках.

> Аналогия: словарь — как **телефонная книга** или **реестр Windows**: по имени параметра находим его значение. Или как таблица Excel из двух столбцов, где ищем через ВПР.

Ключи должны быть **уникальными**: два «Анна» быть не может, второй перезапишет первую.

## Работа со словарём

```python
person = {"name": "Иван", "age": 55, "city": "Москва"}

# Добавить или изменить
person["email"] = "ivan@mail.ru"   # нового ключа не было — добавится
person["age"] = 56                  # ключ был — значение заменится

# Удалить
del person["city"]

# Проверить наличие ключа
if "email" in person:
    print("Почта указана")

print(person)
# {'name': 'Иван', 'age': 56, 'email': 'ivan@mail.ru'}
print(len(person))   # 3
```

### Безопасное получение: get

```python
print(person["phone"])            # ОШИБКА KeyError — такого ключа нет
print(person.get("phone"))        # None — «ничего», без ошибки
print(person.get("phone", "не указан"))   # не указан — значение по умолчанию
```

`None` — специальное значение в Python, означает «пусто, ничего».

## Перебор словаря

```python
prices = {"хлеб": 65, "молоко": 98, "сыр": 420}

for product in prices:                  # перебор ключей
    print(product)

for product, price in prices.items():   # ключи и значения сразу
    print(f"{product}: {price} руб.")

print(list(prices.keys()))     # ['хлеб', 'молоко', 'сыр']
print(list(prices.values()))   # [65, 98, 420]
print(sum(prices.values()))    # 583
```

## Подсчёт с помощью словаря

Классическая задача — посчитать, сколько раз встречается каждое слово:

```python
text = "кот пёс кот рыба пёс кот"
counts = {}
for word in text.split():
    if word in counts:
        counts[word] += 1
    else:
        counts[word] = 1
print(counts)   # {'кот': 3, 'пёс': 2, 'рыба': 1}
```

Короче, с `get`:
```python
counts[word] = counts.get(word, 0) + 1
```

## Список словарей — маленькая база данных

```python
books = [
    {"title": "Мастер и Маргарита", "author": "Булгаков", "year": 1967},
    {"title": "Пикник на обочине", "author": "Стругацкие", "year": 1972},
    {"title": "Идиот", "author": "Достоевский", "year": 1869},
]

for book in books:
    print(f"{book['title']} — {book['author']}, {book['year']}")
```

Это как таблица: каждый словарь — строка, ключи — названия столбцов. Так хранят данные в большинстве реальных программ.

> [!warning] Кавычки внутри f-строки
> Снаружи f-строка в двойных кавычках `"`, значит, ключ внутри — в одинарных: `{book['title']}`.
