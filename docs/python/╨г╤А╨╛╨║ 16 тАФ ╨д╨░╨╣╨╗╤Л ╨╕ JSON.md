## Проблема

Ваша телефонная книга из урока 12 теряет все контакты при закрытии программы. Переменные живут только в оперативной памяти, пока работает программа. Чтобы данные сохранялись — их пишут в **файл** на диск.

## Запись в файл

```python
with open("notes.txt", "w", encoding="utf-8") as file:
    file.write("Первая строка\n")
    file.write("Вторая строка\n")
```

Разберём:
- `open("notes.txt", ...)` — открыть файл `notes.txt`. Он появится **в папке, откуда запущена программа** (у вас — в папке курса в VS Code).
- `"w"` — режим **записи** (write). **Внимание:** если файл уже был — его содержимое **сотрётся**.
- `encoding="utf-8"` — кодировка. **На Windows пишите всегда**, иначе русские буквы превратятся в «кракозябры».
- `with ... as file:` — «открой, дай мне его под именем `file`, а когда закончу — закрой сам». Очень удобно: файл точно закроется, даже если случится ошибка.
- `\n` — символ перевода строки. `write`, в отличие от `print`, сам строку не переносит.

## Режимы открытия

| Режим | Что делает |
|---|---|
| `"r"` | чтение (read) — режим по умолчанию |
| `"w"` | запись с нуля — старое содержимое стирается |
| `"a"` | дозапись в конец (append) — старое сохраняется |

## Чтение файла

```python
# Прочитать всё целиком
with open("notes.txt", "r", encoding="utf-8") as file:
    content = file.read()
print(content)

# Прочитать построчно
with open("notes.txt", "r", encoding="utf-8") as file:
    for line in file:
        print(line.strip())    # strip убирает \n в конце строки
```

## Дозапись — журнал

```python
from datetime import datetime   # подробнее — в следующем уроке

def log(message):
    with open("log.txt", "a", encoding="utf-8") as file:
        file.write(f"{datetime.now()}: {message}\n")

log("Программа запущена")
log("Пользователь вошёл")
```

## Если файла нет

```python
try:
    with open("data.txt", "r", encoding="utf-8") as file:
        print(file.read())
except FileNotFoundError:
    print("Файл не найден, начинаем с чистого листа")
```

## JSON — сохраняем списки и словари

Текстовый файл хорош для строк. А как сохранить словарь или список словарей? Для этого есть формат **JSON** — вы его наверняка встречали: в нём хранят настройки многих программ.

```python
import json

contacts = {
    "Анна": "+7 900 111-22-33",
    "Борис": "+7 900 444-55-66",
}

# Сохранить
with open("contacts.json", "w", encoding="utf-8") as file:
    json.dump(contacts, file, ensure_ascii=False, indent=2)

# Загрузить
with open("contacts.json", "r", encoding="utf-8") as file:
    loaded = json.load(file)

print(loaded["Анна"])
```

- `json.dump(данные, файл)` — записать.
- `json.load(файл)` — прочитать, получаем обратно словарь/список.
- `ensure_ascii=False` — сохранять русские буквы как есть, а не кодами `А`.
- `indent=2` — красивые отступы, файл можно открыть и прочитать глазами.

Откройте `contacts.json` в VS Code — увидите, как он выглядит внутри.

## Шаблон «загрузить — поработать — сохранить»

Этот шаблон будет почти в каждой вашей программе:

```python
import json

FILENAME = "contacts.json"   # константа — заглавными буквами

def load_data():
    try:
        with open(FILENAME, "r", encoding="utf-8") as file:
            return json.load(file)
    except FileNotFoundError:
        return {}            # файла нет — начинаем с пустого словаря

def save_data(data):
    with open(FILENAME, "w", encoding="utf-8") as file:
        json.dump(data, file, ensure_ascii=False, indent=2)

contacts = load_data()
name = input("Имя: ")
phone = input("Телефон: ")
contacts[name] = phone
save_data(contacts)
print(f"Сохранено. Всего контактов: {len(contacts)}")
```

Запустите несколько раз — контакты накапливаются!

## Запомнить

- `with open(имя, режим, encoding="utf-8") as file:` — так открываем файлы всегда.
- `"r"` — читать, `"w"` — перезаписать, `"a"` — дописать.
- `json.dump` / `json.load` — сохранить и загрузить списки и словари.
