## 📊 Статистика

Лучше всего с плагином **Dataview** (Настройки → Сторонние плагины → Обзор → Dataview). Тогда ниже будет видно, сколько задач решено в каждом уроке:

```dataview
TABLE WITHOUT ID
  file.link AS "Урок",
  length(filter(file.tasks, (t) => t.completed)) + " / " + length(file.tasks) AS "Задачи"
WHERE file.folder = this.file.folder AND (урок OR проект)
SORT file.name ASC
```

Без Dataview всё тоже работает: галочки ставятся прямо в уроках и в этом трекере.
