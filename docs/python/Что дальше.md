🎓 **Если вы дошли сюда — вы умеете программировать.** Это не преувеличение: переменные, условия, циклы, функции, структуры данных, файлы — это фундамент, на котором стоит любая программа.

Дальше — выбирать направление по интересу. Каждое из них — это новая «библиотека» и новые проекты.

## Направления

| Направление | С чего начать | Идея проекта |
|---|---|---|
| **Графика и рисование** | модуль `turtle` (встроен в Python) | нарисовать узоры, звёздное небо, часы |
| **Программы с окнами** | модуль `tkinter` (встроен) | калькулятор с кнопками, бухгалтерия с окнами |
| **Работа с Excel** | библиотека `openpyxl` | отчёт из бухгалтерии сразу в .xlsx с графиком |
| **Telegram-бот** | библиотека `aiogram` или `python-telegram-bot` | бот-напоминалка, бот-викторина |
| **Игры** | библиотека `pygame` | змейка, арканоид |
| **Анализ данных** | `pandas` + `matplotlib` | графики своих расходов, погоды, курса валют |
| **Автоматизация** | `pathlib`, `shutil`, `os` (встроены) | разложить фотографии по папкам по дате |

Библиотеки, которые не встроены, ставятся командой в терминале VS Code:
```
pip install openpyxl
```

## Полезные ресурсы

- **docs.python.org/ru/3/** — официальная документация на русском.
- **pythontutor.com** — визуализация выполнения кода по шагам, отлично для понимания циклов и списков.
- **Stepik** — курс «Поколение Python» (бесплатный, много задач с автопроверкой).
- **Codewars** (codewars.com) — короткие задачи-головоломки, уровни от простых (8 kyu) до сложных.
