## Арифметические действия

| Знак | Действие | Пример | Результат |
|---|---|---|---|
| `+` | сложение | `7 + 2` | `9` |
| `-` | вычитание | `7 - 2` | `5` |
| `*` | умножение | `7 * 2` | `14` |
| `/` | деление | `7 / 2` | `3.5` |
| `//` | деление нацело | `7 // 2` | `3` |
| `%` | остаток от деления | `7 % 2` | `1` |
| `**` | степень | `7 ** 2` | `49` |

### Деление нацело и остаток — зачем?

Очень полезная пара. Пример: 135 минут — это сколько часов и минут?

```python
total_minutes = 135
hours = total_minutes // 60     # 2  — сколько целых часов
minutes = total_minutes % 60    # 15 — сколько осталось минут
print(hours, "ч", minutes, "мин")
```

Аналогия: у вас 17 яиц, в коробку влезает 10. `17 // 10 = 1` полная коробка, `17 % 10 = 7` яиц осталось.

**Проверка на чётность:** `число % 2` равно `0` — число чётное, `1` — нечётное. Пригодится в следующем уроке.

### Порядок действий

Как в школе: сначала `**`, потом `*` `/` `//` `%`, потом `+` `-`. Скобки меняют порядок.

```python
print(2 + 3 * 4)      # 14
print((2 + 3) * 4)    # 20
```

Не уверены — ставьте скобки. Лишние скобки не вредят, а читать проще.

### Округление

```python
price = 1234.5678
print(round(price))       # 1235  — до целого
print(round(price, 2))    # 1234.57 — до 2 знаков после точки
```

## f-строки — удобная сборка текста

Раньше мы писали `print("Итого:", total, "руб.")`. Есть способ лучше — **f-строки**:

```python
name = "Иван"
age = 55
print(f"Меня зовут {name}, мне {age} лет.")
```
```
Меня зовут Иван, мне 55 лет.
```

Правило: перед кавычкой буква **`f`**, а внутри фигурных скобок `{}` — переменная или даже вычисление:

```python
price = 120
count = 3
print(f"{count} шт. по {price} руб. = {price * count} руб.")
```
```
3 шт. по 120 руб. = 360 руб.
```

### Форматирование чисел

```python
total = 1234.5678
print(f"Сумма: {total:.2f}")      # Сумма: 1234.57   — 2 знака после точки
print(f"Сумма: {total:,.2f}")     # Сумма: 1,234.57  — с разделителем тысяч
print(f"Процент: {0.157:.1%}")    # Процент: 15.7%
```

`:.2f` — «покажи 2 знака после точки». Это как формат ячейки в Excel: само число не меняется, меняется только то, как оно выглядит.

> [!tip] Фигурные скобки на русской раскладке
> `{` и `}` — это клавиши Х и Ъ на английской раскладке с Shift.

## Запомнить

- `/` — обычное деление (всегда дробное), `//` — нацело, `%` — остаток, `**` — степень.
- `f"текст {переменная}"` — вставка значений в текст.
- `{x:.2f}` — показать с двумя знаками после точки.
