# Урок 07. Логические операторы and, or, not

← [[Урок 06 — Условия if-elif-else]] · Следующий: [[Урок 08 — Цикл while]]

**Цель:** научиться объединять несколько условий в одно.
**Время:** 1 день.

## and — «и»

Условие истинно, только если **оба** условия истинны.

```python
age = int(input("Возраст: "))
has_license = input("Есть права? (да/нет): ")

if age >= 18 and has_license == "да":
    print("Можете арендовать машину")
else:
    print("Аренда невозможна")
```

## or — «или»

Истинно, если **хотя бы одно** условие истинно.

```python
day = input("День недели: ")

if day == "суббота" or day == "воскресенье":
    print("Выходной!")
else:
    print("Рабочий день")
```

> [!warning] Частая ошибка
> ```python
> if day == "суббота" or "воскресенье":   # НЕПРАВИЛЬНО
> ```
> Так писать нельзя: Python поймёт это иначе, чем вы думаете, и условие будет **всегда** истинным. Каждое сравнение пишется полностью: `day == "суббота" or day == "воскресенье"`.

## not — «не»

Переворачивает: `True` → `False`, `False` → `True`.

```python
is_raining = False

if not is_raining:
    print("Идём гулять")
```

## Таблица истинности

| A | B | A and B | A or B |
|---|---|---|---|
| True | True | True | True |
| True | False | False | True |
| False | True | False | True |
| False | False | False | False |

Знакомо? Это как фильтры в Excel: «И» — должны выполниться все фильтры, «ИЛИ» — хотя бы один.

## Диапазон значений

Проверить, что число в диапазоне от 10 до 20:

```python
x = 15
if x >= 10 and x <= 20:
    print("В диапазоне")

# То же самое, короче (так умеет только Python):
if 10 <= x <= 20:
    print("В диапазоне")
```

## Переменные-флажки

Результат сравнения можно сохранить:

```python
age = 55
is_adult = age >= 18          # True
is_pensioner = age >= 65      # False

if is_adult and not is_pensioner:
    print("Трудоспособный возраст")
```

Такие переменные называют **флагами**. Имена флагов удобно начинать с `is_` или `has_`.

## Порядок

Сначала выполняется `not`, потом `and`, потом `or`. Не уверены — ставьте скобки:

```python
if (day == "суббота" or day == "воскресенье") and weather == "солнце":
    print("На дачу!")
```

## Запомнить

- `and` — все условия, `or` — хотя бы одно, `not` — наоборот.
- Каждое сравнение пишем полностью: `x == 1 or x == 2`.
- `10 <= x <= 20` — проверка диапазона.
