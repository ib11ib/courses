## Что такое список

До сих пор в одной переменной — одно значение. А если нужно хранить 30 температур за месяц? 30 переменных — неудобно. Для этого есть **список** (`list`).

```python
temperatures = [12, 15, 9, 18, 21]
names = ["Анна", "Борис", "Вера"]
mixed = [1, "текст", 3.5, True]   # можно и вперемешку, но обычно так не делают
empty = []                        # пустой список
```

Квадратные скобки, элементы через запятую.

> Аналогия: список — это **столбец в Excel**. У каждой ячейки есть номер строки и значение.

## Индексы — номера элементов

Нумерация — **с нуля** (помните `range`?).

```python
names = ["Анна", "Борис", "Вера", "Глеб"]
#          0        1        2       3

print(names[0])    # Анна
print(names[2])    # Вера
print(names[-1])   # Глеб — последний элемент
print(names[-2])   # Вера — предпоследний
print(len(names))  # 4 — количество элементов
```

`names[10]` → ошибка `IndexError: list index out of range` — «нет такого номера».

### Срезы — кусок списка

```python
numbers = [10, 20, 30, 40, 50]
print(numbers[1:3])   # [20, 30]   — с 1-го по 3-й, не включая 3-й
print(numbers[:2])    # [10, 20]   — первые два
print(numbers[2:])    # [30, 40, 50] — с 2-го до конца
```

## Изменение списка

```python
shopping = ["хлеб", "молоко"]

shopping.append("сыр")        # добавить в конец
print(shopping)               # ['хлеб', 'молоко', 'сыр']

shopping[0] = "батон"         # заменить элемент
print(shopping)               # ['батон', 'молоко', 'сыр']

shopping.remove("молоко")     # удалить по значению
print(shopping)               # ['батон', 'сыр']

last = shopping.pop()         # удалить последний и вернуть его
print(last, shopping)         # сыр ['батон']

shopping.insert(0, "масло")   # вставить на позицию 0
print(shopping)               # ['масло', 'батон']
```

Конструкция `список.действие()` называется **метод** — команда, «привязанная» к объекту. Как контекстное меню у файла: правый клик → «Переименовать».

## Проверка «есть ли в списке»

```python
fruits = ["яблоко", "груша", "слива"]
if "груша" in fruits:
    print("Груша есть")
if "банан" not in fruits:
    print("Бананов нет")
```

## Перебор списка

```python
prices = [120, 85, 340, 60]
for price in prices:
    print(f"Цена: {price} руб.")
```

Если нужен и номер, и значение — `enumerate`:

```python
tasks = ["позвонить врачу", "купить хлеб", "оплатить свет"]
for number, task in enumerate(tasks, start=1):
    print(f"{number}. {task}")
```
```
1. позвонить врачу
2. купить хлеб
3. оплатить свет
```

## Полезные функции для чисел в списке

```python
numbers = [5, 2, 9, 1, 7]
print(sum(numbers))      # 24 — сумма
print(max(numbers))      # 9  — максимум
print(min(numbers))      # 1  — минимум
print(sorted(numbers))   # [1, 2, 5, 7, 9] — новый отсортированный список
numbers.sort()           # отсортировать сам список
numbers.reverse()        # перевернуть
print(numbers)           # [9, 7, 5, 2, 1]
```

## Наполнение списка в цикле

```python
guests = []
while True:
    name = input("Имя гостя (пусто — конец): ")
    if name == "":
        break
    guests.append(name)
print(f"Всего гостей: {len(guests)}")
```

## Запомнить

- Список: `[a, b, c]`. Индексы с нуля, `[-1]` — последний.
- `append` — добавить, `remove` — удалить по значению, `pop` — удалить по номеру.
- `in` — проверка наличия. `for x in список:` — перебор.
