## Что такое модуль

Модуль — это файл с готовыми функциями. Python поставляется с сотнями модулей — это **стандартная библиотека** («батарейки в комплекте»). Вы уже использовали один — `json`.

```python
import math

print(math.sqrt(16))    # 4.0 — квадратный корень
print(math.pi)          # 3.141592653589793
print(math.ceil(4.1))   # 5 — округление ВВЕРХ (пригодится для рулонов обоев!)
print(math.floor(4.9))  # 4 — округление вниз
```

> Аналогия: модуль — как **набор инструментов** в отдельном ящике. `import` — достать ящик. Дальше `ящик.инструмент`.

### Способы импорта

```python
import math                 # весь модуль: math.sqrt(16)
from math import sqrt, pi   # только нужное: sqrt(16)
import datetime as dt       # с коротким псевдонимом: dt.date.today()
```

Импорты пишут **в самом начале** файла.

## random — случайности

```python
import random

print(random.randint(1, 6))           # случайное целое от 1 до 6 (включительно!)
print(random.random())                # случайное дробное от 0 до 1
print(random.choice(["орёл", "решка"]))  # случайный элемент списка

cards = ["туз", "король", "дама", "валет"]
random.shuffle(cards)                 # перемешать список
print(cards)

print(random.sample(range(1, 50), 6)) # 6 разных чисел — как лотерея
```

## datetime — дата и время

```python
from datetime import date, datetime, timedelta

today = date.today()
print(today)                          # 2026-11-17
print(today.year, today.month, today.day)

now = datetime.now()
print(now.strftime("%d.%m.%Y %H:%M")) # 17.11.2026 14:30 — привычный формат

birthday = date(1971, 5, 20)
age_days = (today - birthday).days
print(f"Прожито дней: {age_days}")

next_week = today + timedelta(days=7)
print(f"Через неделю: {next_week.strftime('%d.%m.%Y')}")
```

Коды формата: `%d` — день, `%m` — месяц, `%Y` — год (4 цифры), `%H` — часы, `%M` — минуты.

## time — паузы

```python
import time

print("Подождите...")

print("Готово!")
```

## os и pathlib — работа с файлами и папками

Это близко вам как IT-шнику:

```python
from pathlib import Path

folder = Path(".")                    # текущая папка
for item in folder.iterdir():
    if item.is_file():
        print(item.name, item.stat().st_size, "байт")

print(Path("notes.txt").exists())     # есть ли файл
```

## Свой модуль

Любой ваш `.py` файл — уже модуль! Создайте файл `my_input.py`:

```python
# my_input.py
def ask_int(prompt):
    while True:
        try:
            return int(input(prompt))
        except ValueError:
            print("Нужно целое число.")
```

И в другом файле **в той же папке**:

```python
from my_input import ask_int

age = ask_int("Возраст: ")
```

Так большие программы разбивают на части: каждый файл отвечает за своё.

## Запомнить

- `import модуль` → `модуль.функция()`.
- `random.randint(a, b)` — включает обе границы (в отличие от `range`!).
- `datetime` — даты, `strftime("%d.%m.%Y")` — привычный вид.
- Свой `.py` файл — это тоже модуль.
