## Команда input

До сих пор программа только говорила. Теперь она научится **слушать**.

```python
name = input("Как вас зовут? ")
print("Приятно познакомиться,", name)
```

Что происходит:
1. Python выводит вопрос `Как вас зовут? ` и **ждёт**.
2. Вы набираете ответ в терминале внизу и жмёте **Enter**.
3. То, что вы набрали, попадает в переменную `name`.

> [!tip] Пробел в конце вопроса
> Ставьте пробел перед закрывающей кавычкой: `"Как вас зовут? "`. Иначе ответ прилипнет к вопросу: `Как вас зовут?Иван`.

## Главное правило input

**`input` всегда возвращает текст (`str`)**. Даже если вы ввели цифры.

```python
age = input("Сколько вам лет? ")   # вводим 55
print(type(age))                   # <class 'str'>
print(age + 1)                     # ОШИБКА TypeError!
```

Python получил не число 55, а текст «55». А к тексту нельзя прибавить число.

## Преобразование типов

Чтобы превратить текст в число — «обернуть» его:

| Команда | Превращает в | Пример |
|---|---|---|
| `int(...)` | целое число | `int("55")` → `55` |
| `float(...)` | дробное число | `float("36.6")` → `36.6` |
| `str(...)` | текст | `str(55)` → `"55"` |

```python
age = int(input("Сколько вам лет? "))
print("Через 10 лет вам будет", age + 10)
```

Читаем **изнутри наружу**: сначала `input(...)` получает текст, потом `int(...)` превращает его в число, потом кладём в `age`.

То же в два шага (если так понятнее — пишите так):

```python
age_text = input("Сколько вам лет? ")
age = int(age_text)
```

### Когда преобразование не получится

```python
int("пятьдесят")   # ValueError: invalid literal for int()
int("3.5")         # ValueError — для дробных нужен float
float("3,5")       # ValueError — нужна точка, не запятая
```

`ValueError` — значит «не могу превратить это значение». Пока что просто вводите правильные данные. Как программе защититься от неправильного ввода — узнаем в [[Урок 15 — Ошибки и try-except]].

## Пример: мини-калькулятор

```python
print("=== Калькулятор сложения ===")
first = float(input("Первое число: "))
second = float(input("Второе число: "))
result = first + second
print("Сумма:", result)
```

## Запомнить

- `input("вопрос ")` — спросить и получить ответ.
- Ответ **всегда текст**. Для чисел: `int(input(...))` или `float(input(...))`.
- `ValueError` — значит не смогли превратить текст в число.
