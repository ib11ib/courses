# Урок 01. Установка Python и редактора кода

← [[00 Старт здесь]] · Следующий: [[Урок 02 — Первая программа]]

**Цель урока:** поставить на компьютер Python и удобный редактор, запустить первую строчку кода.
**Время:** 1 день.

## Что мы ставим и зачем

- **Python** — это «переводчик». Вы пишете команды текстом, а Python переводит их в действия компьютера. Без него файл с кодом — просто текстовый файл.
- **VS Code** (Visual Studio Code) — редактор, в котором удобно писать код. Это как Word, только для программ: подсвечивает слова цветом, подсказывает ошибки, запускает программу одной кнопкой. Бесплатный, от Microsoft.

> Аналогия: Python — это двигатель, VS Code — это удобный салон с приборной панелью. Ездить можно и без салона, но неудобно.

---

## Шаг 1. Скачать Python

1. Открыть сайт **python.org** → меню **Downloads** → большая жёлтая кнопка **Download Python 3.x.x** (берём последнюю версию 3.12 или новее).
2. Скачается файл вроде `python-3.13.0-amd64.exe`.

## Шаг 2. Установить Python — ВАЖНАЯ ГАЛОЧКА

1. Запустить скачанный файл.
2. В самом первом окне **внизу** есть галочка:
   **☑ Add python.exe to PATH** — **обязательно поставить!**
   (Также можно поставить «Use admin privileges when installing py.exe».)
3. Нажать **Install Now**.
4. В конце, если появится надпись **Disable path length limit** — нажать на неё (это снимает старое ограничение Windows на длину путей, вреда нет).
5. **Close**.

> [!info] Зачем PATH?
> PATH — это список папок, где Windows ищет программы, когда вы пишете команду. Без галочки Windows просто не найдёт Python, когда вы напишете `python`. Вы это и так знаете по работе — тут то же самое.

## Шаг 3. Проверить, что Python установился

1. Нажать **Win + R**, ввести `cmd`, Enter. Откроется чёрное окно командной строки.
2. Ввести и нажать Enter:
   ```
   python --version
   ```
3. Должно появиться что-то вроде `Python 3.13.0`. ✅

**Если вместо этого открылся Microsoft Store** или написано «не является внутренней командой»:
- Попробовать команду `py --version`. Если она работает — всё в порядке, просто везде вместо `python` пишите `py`.
- Если не работает — переустановить Python, **не забыв галочку PATH**.
- Если открывается Store: Пуск → «Управление псевдонимами выполнения приложений» → выключить два переключателя «python.exe» и «python3.exe».

## Шаг 4. Установить VS Code

1. Сайт **code.visualstudio.com** → **Download for Windows**.
2. Запустить установщик. На шаге «Дополнительные задачи» поставить все галочки, особенно:
   - ☑ Добавить действие «Открыть с помощью Code» в контекстное меню файла
   - ☑ Добавить действие «Открыть с помощью Code» в контекстное меню папки
   - ☑ Добавить в PATH
3. Установить и запустить.

**Русский язык (по желанию):** VS Code обычно сам предлагает поставить русский языковой пакет (справа внизу). Можно согласиться. В уроках названия меню даны на английском, в скобках — по-русски.

## Шаг 5. Установить расширение Python в VS Code

1. Слева в VS Code есть столбик иконок. Нажать на иконку из **четырёх квадратиков** (Extensions / Расширения) или `Ctrl + Shift + X`.
2. В поиске набрать `Python`.
3. Первое в списке — **Python от Microsoft** (с синей галочкой). Нажать **Install**.

## Шаг 6. Создать папку для курса

1. В проводнике создать папку, например: `D:\Python_курс` (или в «Документах»).
2. В VS Code: **File → Open Folder** (Файл → Открыть папку) → выбрать эту папку.
3. Если спросит «Do you trust the authors?» — нажать **Yes, I trust**.

Все программы курса будем сохранять в эту папку: `урок02.py`, `урок03_задача1.py` и т.д.

> [!tip] Имена файлов
> Лучше называть файлы латиницей без пробелов: `lesson02_task1.py`. Русские имена тоже работают, но латиница избавит от редких проблем.

## Шаг 7. Первый запуск

1. В VS Code слева, в панели папки, нажать иконку **«New File»** (листик с плюсом) и назвать файл `hello.py`. Важно: окончание `.py` — именно по нему компьютер понимает, что это программа на Python.
2. Написать в файле одну строку:
   ```python
   print("Привет, мир!")
   ```
3. Сохранить: `Ctrl + S`.
4. Нажать **треугольник ▶** справа вверху (Run Python File).
5. Внизу откроется панель **Terminal** (Терминал), и в ней появится:
   ```
   Привет, мир!
   ```

🎉 **Поздравляю, вы запустили первую программу!**

Если справа вверху треугольника нет — проверьте, что файл называется именно `hello.py` и что расширение Python установлено (шаг 5). Если внизу ошибка про выбор интерпретатора — нажать `Ctrl + Shift + P`, набрать `Python: Select Interpreter` и выбрать установленный Python 3.

## Полезные горячие клавиши VS Code

| Клавиши | Что делает |
|---|---|
| `Ctrl + S` | Сохранить файл (делать всегда перед запуском!) |
| `Ctrl + /` | Закомментировать / раскомментировать строку |
| `Ctrl + Z` | Отменить |
| `Ctrl` + `Ё` (клавиша слева от 1) | Показать/скрыть терминал |
| `Ctrl + +` / `Ctrl + -` | Крупнее / мельче шрифт |

> [!tip] Удобство для глаз
> Если шрифт мелкий: **File → Preferences → Settings** (Файл → Параметры → Настройки), найти `Font Size`, поставить 16–18. Там же `Auto Save` → `afterDelay`, чтобы файл сохранялся сам.

## Запомнить

- Python — переводчик команд, VS Code — редактор.
- Файлы программ заканчиваются на `.py`.
- Перед запуском — `Ctrl + S`, потом ▶.
- Результат программы появляется внизу, в **терминале**.
