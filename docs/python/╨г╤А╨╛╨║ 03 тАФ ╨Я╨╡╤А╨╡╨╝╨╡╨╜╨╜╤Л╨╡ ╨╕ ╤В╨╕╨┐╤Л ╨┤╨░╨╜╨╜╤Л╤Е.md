**Цель:** понять, что такое переменная, научиться хранить в ней данные и различать типы: числа, текст, логические значения.
**Время:** 1–2 дня.

## Что такое переменная

Переменная — это **коробка с наклейкой**. На наклейке — имя, внутри — значение.

```python
age = 55
name = "Иван"
```

Читается так: «положить 55 в коробку с наклейкой `age`». Знак `=` в программировании — **не «равно»**, а **«присвоить»**: взять то, что справа, и положить в коробку слева.

> Аналогия для IT-шника: переменная — как ярлык на файл. Имя ярлыка одно, а содержимое можно поменять.

Теперь переменную можно использовать:

```python
age = 55
name = "Иван"
print(name, "—", age, "лет")
```
```
Иван — 55 лет
```

### Значение можно менять

```python
money = 1000
print(money)
money = 750
print(money)
```
```
1000
750
```
Старое значение пропало, в коробке лежит новое.

### Переменная из переменной

```python
price = 120
count = 3
total = price * count
print("Итого:", total)
```
```
Итого: 360
```

### Изменить значение «на основе самого себя»

```python
balance = 1000
balance = balance + 500   # взять старое, прибавить 500, положить обратно
print(balance)            # 1500
balance += 200            # то же самое, короткая запись
print(balance)            # 1700
```

Короткие записи: `+=`, `-=`, `*=`, `/=`.

## Правила имён переменных

✅ Можно: `age`, `user_name`, `total_price`, `price2`
❌ Нельзя: `2price` (начинается с цифры), `user name` (пробел), `print` (занято командой)

Хорошая привычка — **понятные имена** на английском маленькими буквами через `_`:
- плохо: `a = 120`, `x = 3`
- хорошо: `price = 120`, `count = 3`

Через месяц `a` и `x` вам ничего не скажут, а `price` скажет всё.

## Типы данных

У каждого значения есть **тип** — что это за «вещество» в коробке.

| Тип | Название | Примеры | Аналогия |
|---|---|---|---|
| `int` | целое число | `55`, `-3`, `0` | ячейка Excel формата «Числовой» без дробей |
| `float` | дробное число | `3.14`, `-0.5`, `36.6` | число с запятой (в Python — **точка!**) |
| `str` | строка (текст) | `"Привет"`, `"55"` | ячейка формата «Текстовый» |
| `bool` | логическое | `True`, `False` | галочка: стоит / не стоит |

Узнать тип — команда `type`:

```python
print(type(55))        # <class 'int'>
print(type(36.6))      # <class 'float'>
print(type("55"))      # <class 'str'>
print(type(True))      # <class 'bool'>
```

> [!warning] Главная ловушка
> `55` и `"55"` — **разные вещи**. Первое — число, с ним можно считать. Второе — текст из двух символов «5» и «5».
> ```python
> print(55 + 5)      # 60
> print("55" + "5")  # 555  — текст просто склеился!
> print("55" + 5)    # ОШИБКА TypeError: нельзя складывать текст и число
> ```

> [!warning] Дробные числа — через точку
> `3.5` — правильно. `3,5` — Python поймёт как два отдельных числа 3 и 5.

## Операции с текстом

```python
first = "Иван"
last = "Петров"
full = first + " " + last     # склеивание
print(full)                    # Иван Петров
print("-" * 20)                # -------------------- (повторить 20 раз)
print(len(full))               # 13 — длина строки, количество символов
```

## Запомнить

- `=` — это «положить в коробку», не «равно».
- Имена — понятные, латиницей, через `_`.
- `int` — целые, `float` — дробные (через точку), `str` — текст в кавычках, `bool` — `True`/`False`.
- `"5" + "5"` = `"55"`, а `5 + 5` = `10`. Текст и число складывать нельзя.
