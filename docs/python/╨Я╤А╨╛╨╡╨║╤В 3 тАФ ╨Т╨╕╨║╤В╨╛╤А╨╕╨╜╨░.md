# Проект 3. Викторина

## Описание

Программа-викторина: вопросы хранятся в файле, их можно добавлять прямо из программы. Есть темы, перемешивание вопросов и вариантов ответа, таймер, таблица лучших результатов. Можно наполнить своими вопросами и сыграть с семьёй или друзьями.

Пример:
```
=== ВИКТОРИНА ===
Игрок: Иван
Темы: 1-История 2-География 3-Кино 4-Все темы
Тема: 2
Сколько вопросов (1–10): 5

Вопрос 1 из 5 (География)
Какая река самая длинная в Европе?
  1) Дунай
  2) Волга
  3) Днепр
  4) Урал
Ваш ответ: 2
✅ Верно! (+10 очков, ответ за 4 сек — бонус +3)

...

Итог: 4 из 5, 47 очков. Место в таблице рекордов: 2
```

## Формат файла вопросов `questions.json`

```json
[
  {
    "topic": "География",
    "question": "Какая река самая длинная в Европе?",
    "options": ["Дунай", "Волга", "Днепр", "Урал"],
    "answer": "Волга"
  }
]
```

Ответ хранится **текстом**, а не номером — потому что варианты будут перемешиваться, и номер правильного ответа каждый раз разный.

Для начала создайте файл вручную на 15–20 вопросов (по 5+ на 3 темы). Можно попросить нейросеть: *«Составь 20 вопросов викторины по темам История, География, Кино в таком JSON-формате: (вставить формат)»* — это разрешено, это данные, а не код 🙂

## Этапы

- [ ] **Этап 0. План.** Функции, структуры данных, псевдокод.
- [ ] **Этап 1. Основа.** Загрузить вопросы из файла, задать все по порядку, проверить ответы (пользователь вводит номер варианта), в конце — сколько правильных.
- [ ] **Этап 2. Перемешивание.** Порядок вопросов случайный, порядок вариантов ответа — тоже. Проверка ответа должна работать правильно после перемешивания.
- [ ] **Этап 3. Темы и количество.** Выбор темы (или все), выбор количества вопросов. Если в теме меньше вопросов, чем запрошено — сообщить и задать сколько есть.
- [ ] **Этап 4. Очки и время.** За правильный ответ 10 очков. Бонус за скорость: ответил быстрее 5 секунд — +3, быстрее 10 секунд — +1. Подсказка: `time.time()` возвращает текущее время в секундах — засеките до и после `input`.
- [ ] **Этап 5. Таблица рекордов.** Имя игрока, очки, тема, дата — в `scores.json`. Показ топ-10 по очкам. Пункт меню «Рекорды».
- [ ] **Этап 6. Редактор вопросов.** Пункт меню «Добавить вопрос»: тема (выбрать существующую или ввести новую), текст, 4 варианта, номер правильного. Проверки: варианты не пустые и не повторяются. Сохранение в `questions.json`.
- [ ] **Этап 7. Работа над ошибками.** После игры — показать вопросы, на которые ответили неправильно, с правильными ответами. Пункт «Повторить ошибки» — сыграть только по ним.
- [ ] **Этап 8 (бонус). Режим на двоих.** Два игрока отвечают по очереди, в конце — победитель.
- [ ] **Этап 9. Финальное ревью.**
