# Проект 1. Игра «Угадай число»

← [[Урок 18 — Как писать программу и искать ошибки]] · Следующий: [[Проект 2 — Домашняя бухгалтерия]]

**Время:** 4–6 дней.
**Что используем:** `random`, циклы, условия, функции, `try/except`, файлы JSON.

## Описание

Компьютер загадывает число, игрок угадывает. После каждой попытки компьютер подсказывает: «больше» или «меньше». Игра запоминает рекорды между запусками.

Пример игры:
```
=== УГАДАЙ ЧИСЛО ===
Выберите уровень: 1 — лёгкий (1–50), 2 — средний (1–100), 3 — сложный (1–1000): 2
Я загадал число от 1 до 100. У вас 7 попыток.
Попытка 1: 50
Моё число меньше. Осталось попыток: 6
Попытка 2: 25
Моё число больше. Осталось попыток: 5
Попытка 3: 37
🎉 Угадали за 3 попытки! Это новый рекорд уровня «средний»!
Сыграть ещё? (да/нет):
```

## Как работать над проектом

Проект разбит на **этапы**. Каждый этап — это работающая программа, которая умеет чуть больше предыдущей. Закончили этап → проверили у наставника → следующий этап. **Не переходите дальше, пока этап не получил ЗАЧЁТ.**

Сохраняйте копию после каждого этапа: `guess_v1.py`, `guess_v2.py`... Если что-то сломаете — будет куда откатиться.

## Этапы

- [ ] **Этап 0. План.** Список функций с описанием и псевдокод главного цикла игры.
- [ ] **Этап 1. Основа.** Компьютер загадывает число от 1 до 100. Игрок угадывает в цикле, получает подсказки «больше/меньше», пока не угадает. В конце — количество попыток.
- [ ] **Этап 2. Защита ввода.** Программа не падает при вводе букв, пустой строки, числа вне диапазона (сообщить «число должно быть от 1 до 100», попытку не засчитывать).
- [ ] **Этап 3. Ограничение попыток.** У игрока ограниченное число попыток (7 для 1–100). Закончились — «Вы проиграли, я загадал ...».
- [ ] **Этап 4. Уровни сложности.** Три уровня: 1–50 (6 попыток), 1–100 (7 попыток), 1–1000 (10 попыток). Подсказка: храните настройки уровней в словаре.
- [ ] **Этап 5. Повтор игры.** После окончания — «Сыграть ещё?». В конце сессии — статистика: сколько игр, сколько побед, процент побед.
- [ ] **Этап 6. Рекорды.** Лучший результат (минимум попыток) для каждого уровня сохраняется в `records.json` и загружается при запуске. Новый рекорд — поздравление. Пункт меню «Показать рекорды».
- [ ] **Этап 7 (бонус). Наоборот.** Режим, где **вы** загадываете число, а **компьютер** угадывает. Вы отвечаете «больше», «меньше», «угадал». Компьютер должен угадывать за минимальное число попыток. Подсказка: каждый раз называть середину оставшегося диапазона.
- [ ] **Этап 8. Финальное ревью.** Отправить весь код на итоговое ревью.
