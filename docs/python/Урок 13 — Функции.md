## Зачем функции

Вы уже пользовались функциями: `print()`, `input()`, `len()`, `int()`. Это готовые команды. Теперь научимся делать **свои**.

Представьте, что в программе 5 раз нужно вывести красивую рамку. Копировать 3 строки 5 раз? А если потом захотите поменять звёздочки на решётки — менять в 5 местах. Функция решает это: пишем один раз, вызываем сколько угодно.

> Аналогия: функция — как **макрос в Excel** или **ярлык с сохранёнными параметрами**. Записали последовательность действий один раз — запускаем по имени.

## Создание функции

```python
def say_hello():
    print("Здравствуйте!")
    print("Рад вас видеть.")

say_hello()
say_hello()
```

- `def` — «определить» (define).
- `say_hello` — имя функции (правила те же, что для переменных).
- `()` — скобки, обязательно.
- `:` и отступ — как у `if` и циклов.

**Важно:** `def` только **создаёт** функцию, но не запускает её. Запуск (вызов) — `say_hello()`. Функцию нужно определить **выше**, чем вызвать.

## Параметры — данные для функции

```python
def greet(name):
    print(f"Здравствуйте, {name}!")

greet("Иван")
greet("Анна")
```

`name` — **параметр**, «пустая коробка», в которую при вызове кладётся значение. `"Иван"` — **аргумент**, то, что мы передали.

Несколько параметров:

```python
def print_receipt(product, price, count):
    total = price * count
    print(f"{product}: {count} x {price} = {total} руб.")

print_receipt("Хлеб", 65, 2)
print_receipt("Сыр", 420, 1)
```

## return — функция возвращает результат

До сих пор функции что-то **печатали**. Но чаще функция должна **посчитать и отдать** результат, чтобы с ним можно было работать дальше.

```python
def area(length, width):
    return length * width

room1 = area(4, 5)
room2 = area(3, 3.5)
print(f"Общая площадь: {room1 + room2} м²")
```

`return` — «вернуть». Функция заканчивает работу и отдаёт значение туда, откуда её вызвали. Как `input()` отдаёт введённый текст, а `len()` — число.

> [!warning] print против return
> ```python
> def add_print(a, b):
>     print(a + b)      # просто показывает на экране
>
> def add_return(a, b):
>     return a + b      # отдаёт результат
>
> x = add_print(2, 3)   # на экране 5, но x = None!
> y = add_return(2, 3)  # на экране ничего, но y = 5
> print(y * 10)         # 50 — с результатом можно работать
> ```
> **Правило:** функция, которая что-то считает, должна **возвращать** (`return`), а не печатать. Печатать будет тот, кто её вызвал.

После `return` функция сразу завершается. Код ниже в ней не выполнится:

```python
def check_age(age):
    if age >= 18:
        return "взрослый"
    return "ребёнок"     # сюда дойдём, только если первый return не сработал
```

## Функция возвращает True/False

```python
def is_even(number):
    return number % 2 == 0

if is_even(10):
    print("Чётное")
```

Такие функции удобно называть с `is_` — читается как вопрос: «чётное ли?».

## Запомнить

- `def имя(параметры):` — создать функцию. `имя(аргументы)` — вызвать.
- `return` — вернуть результат. Без `return` функция возвращает `None`.
- Считающая функция — **возвращает**, а не печатает.
