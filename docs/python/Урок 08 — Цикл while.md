## Зачем циклы

Вывести числа от 1 до 5 можно так:
```python
print(1)
print(2)
print(3)
print(4)
print(5)
```
А от 1 до 1000? Для повторяющихся действий есть **циклы**.

## while — «пока»

```python
count = 1
while count <= 5:
    print(count)
    count += 1
print("Готово")
```
```
1
2
3
4
5
Готово
```

Как это работает:
1. Проверяем условие `count <= 5`. Правда? → выполняем тело (строки с отступом).
2. Возвращаемся наверх, снова проверяем условие.
3. Как только условие стало `False` — выходим из цикла и идём дальше.

Один проход тела цикла называется **итерация**.

> [!danger] Бесконечный цикл
> Если забыть `count += 1`, то `count` всегда будет 1, условие всегда правда, и программа будет печатать `1` вечно.
> **Как остановить:** нажать в терминале `Ctrl + C`. Запомните эту комбинацию — она ещё пригодится.

## Пошаговая проверка «на бумажке»

Полезный приём — **трассировка**: проследить значения переменных по шагам в таблице.

```python
total = 0
n = 1
while n <= 4:
    total += n
    n += 1
print(total)
```

| Шаг | n (до) | условие n <= 4 | total (после) | n (после) |
|---|---|---|---|---|
| 1 | 1 | True | 1 | 2 |
| 2 | 2 | True | 3 | 3 |
| 3 | 3 | True | 6 | 4 |
| 4 | 4 | True | 10 | 5 |
| 5 | 5 | False | — выход — | |

Выведет `10`. Если код ведёт себя непонятно — нарисуйте такую таблицу. Это лучший способ понять цикл.

## Цикл «пока не введут правильно»

```python
password = input("Пароль: ")
while password != "python":
    print("Неверно, попробуйте ещё")
    password = input("Пароль: ")
print("Вход выполнен")
```

## break — аварийный выход

`break` немедленно прерывает цикл.

```python
while True:          # «вечный» цикл — условие всегда правда
    answer = input("Введите команду (выход — стоп): ")
    if answer == "стоп":
        break
    print(f"Вы ввели: {answer}")
print("Пока!")
```

`while True` + `break` — очень частая конструкция: «повторяй, пока не скажу стоп».

## continue — пропустить итерацию

`continue` — пропустить остаток тела и сразу перейти к следующей проверке.

```python
n = 0
while n < 10:
    n += 1
    if n % 2 == 0:
        continue     # чётные пропускаем
    print(n)         # выведет 1 3 5 7 9
```

## Накопление суммы

```python
total = 0
while True:
    price = float(input("Цена товара (0 — конец): "))
    if price == 0:
        break
    total += price
print(f"Итого: {total:.2f} руб.")
```

## Запомнить

- `while условие:` — повторять, пока условие правда.
- Внутри цикла что-то должно меняться, иначе он бесконечный. Стоп — `Ctrl + C`.
- `break` — выйти из цикла, `continue` — перейти к следующей итерации.
- Не понятно, что делает цикл — рисуем таблицу трассировки.
