# Урок 14. Функции. Продолжение

← [[Урок 13 — Функции]] · Следующий: [[Урок 15 — Ошибки и try-except]]

**Цель:** аргументы по умолчанию, именованные аргументы, область видимости, документирование функций.
**Время:** 1–2 дня.

## Значения по умолчанию

```python
def greet(name, greeting="Здравствуйте"):
    print(f"{greeting}, {name}!")

greet("Иван")                   # Здравствуйте, Иван!
greet("Анна", "Доброе утро")    # Доброе утро, Анна!
```

Если аргумент не передали — берётся значение по умолчанию. Вы уже это видели: `print(..., end=" ")` — у `end` по умолчанию перевод строки.

Параметры со значением по умолчанию пишутся **после** обычных.

## Именованные аргументы

Можно указывать, какой аргумент куда идёт — тогда порядок не важен:

```python
def make_order(product, count, delivery):
    print(f"{product} × {count}, доставка: {delivery}")

make_order("Чайник", 1, "курьер")
make_order(delivery="самовывоз", product="Тостер", count=2)
```

Когда параметров много, именованные аргументы делают вызов понятнее.

## Область видимости

Переменные, созданные **внутри** функции, живут **только внутри** неё.

```python
def calculate():
    result = 42
    print(result)

calculate()     # 42
print(result)   # ОШИБКА NameError: name 'result' is not defined
```

> Аналогия: функция — как **отдельная комната** со своими вещами. Что положили в комнате — снаружи не видно. Это хорошо: функции не мешают друг другу, в разных функциях можно использовать одинаковые имена.

Снаружи функции данные приходят **через параметры**, а уходят наружу **через return**. Это правильный путь.

```python
# Плохо: функция зависит от внешней переменной
tax = 0.13
def net_salary(gross):
    return gross * (1 - tax)

# Хорошо: всё нужное передаётся явно
def net_salary(gross, tax=0.13):
    return gross * (1 - tax)
```

## Возврат нескольких значений

```python
def min_max(numbers):
    return min(numbers), max(numbers)

low, high = min_max([5, 2, 9, 1])
print(low, high)   # 1 9
```

## Документация функции

Первая строка в тройных кавычках — **docstring**, описание функции:

```python
def bmi(weight, height):
    """Считает индекс массы тела. weight — кг, height — метры."""
    return weight / height ** 2
```

Наведите мышку на `bmi` в VS Code — увидите это описание. Полезная привычка.

## Функции вызывают функции

Большая задача делится на маленькие:

```python
def get_number(prompt):
    """Спрашивает число у пользователя."""
    return float(input(prompt))

def calculate_total(price, count, discount=0):
    """Считает итог с учётом скидки в процентах."""
    total = price * count
    return total - total * discount / 100

def main():
    price = get_number("Цена: ")
    count = get_number("Количество: ")
    discount = get_number("Скидка %: ")
    print(f"К оплате: {calculate_total(price, count, discount):.2f}")

main()
```

Функция `main()` («главная») — общепринятый способ собрать программу. Читаешь `main` — и сразу понятен весь план программы.

## Запомнить

- `def f(a, b=10):` — у `b` значение по умолчанию.
- Переменные внутри функции снаружи не видны.
- Вход в функцию — параметры, выход — `return`.
- `main()` — главная функция с планом всей программы.
