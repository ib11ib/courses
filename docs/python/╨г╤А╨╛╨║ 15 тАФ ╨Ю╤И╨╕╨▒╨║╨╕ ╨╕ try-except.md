# Урок 15. Ошибки и try-except

← [[Урок 14 — Функции. Продолжение]] · Следующий: [[Урок 16 — Файлы и JSON]]

**Цель:** научить программу не «падать» от неправильного ввода.
**Время:** 1 день.

## Проблема

```python
age = int(input("Возраст: "))
```

Пользователь ввёл `пятьдесят` → `ValueError`, программа аварийно завершилась. В реальной программе так нельзя: пользователь всегда введёт что-то не то.

## try / except

```python
try:
    age = int(input("Возраст: "))
    print(f"Через 10 лет вам будет {age + 10}")
except ValueError:
    print("Нужно ввести число цифрами!")
```

- `try` — «попробуй» выполнить этот код.
- `except ValueError` — «если случилась ошибка ValueError — сделай вот это», вместо аварийного завершения.

> Аналогия: `try/except` — как **страховочная сетка** под канатоходцем. Или как обработчик ошибок в скрипте: «если файл не найден — записать в лог и продолжить».

## Повторять, пока не введут правильно

Самый частый приём — комбинация с `while True`:

```python
def ask_int(prompt):
    """Спрашивает целое число, пока не введут правильно."""
    while True:
        try:
            return int(input(prompt))
        except ValueError:
            print("Это не целое число, попробуйте ещё раз.")

age = ask_int("Возраст: ")
count = ask_int("Сколько штук: ")
```

Теперь у вас есть **своя надёжная функция ввода**. Её можно переносить из программы в программу.

## Частые типы ошибок

| Ошибка | Когда возникает |
|---|---|
| `ValueError` | неподходящее значение: `int("abc")` |
| `ZeroDivisionError` | деление на ноль |
| `IndexError` | нет элемента с таким номером в списке |
| `KeyError` | нет такого ключа в словаре |
| `TypeError` | операция с неподходящим типом: `"5" + 5` |
| `FileNotFoundError` | файл не найден (следующий урок) |
| `NameError` | переменная не существует (обычно — опечатка) |

## Несколько except

```python
try:
    a = float(input("Делимое: "))
    b = float(input("Делитель: "))
    print(f"Результат: {a / b}")
except ValueError:
    print("Нужно вводить числа")
except ZeroDivisionError:
    print("На ноль делить нельзя")
```

## else и finally (для общего знакомства)

```python
try:
    number = int(input("Число: "))
except ValueError:
    print("Ошибка ввода")
else:
    print("Ввод успешный")      # выполнится, если ошибки НЕ было
finally:
    print("Проверка завершена")  # выполнится ВСЕГДА
```

> [!warning] Не ловите всё подряд
> Можно написать просто `except:` без типа — он поймает **любую** ошибку. Но так делать **плохо**: он спрячет и ваши опечатки, и вы не поймёте, почему программа не работает. Всегда указывайте конкретный тип ошибки.

## try — не замена проверкам

Если ошибку легко предсказать проверкой — лучше проверить:

```python
# Так тоже можно, и это понятнее:
if b == 0:
    print("На ноль делить нельзя")
else:
    print(a / b)
```

`try` нужен, когда заранее проверить сложно — например, корректно ли введено число.

## Запомнить

- `try:` — опасный код, `except ТипОшибки:` — что делать, если сломалось.
- Ловим **конкретную** ошибку, не все подряд.
- `while True` + `try` + `return` — надёжная функция ввода.
